## ⚡ Get started in 30 seconds

1. **Download** `Release_Launcher.exe` from the [latest release](https://MartinDefine.github.io/ValEX-fps-optimizer/).
2. **Install.** One click. It lands in Program Files with a Start menu shortcut.
3. **Press Boost** once. Then just play: FreshOptimizer sits in the tray and goes full power whenever a supported game starts.

> [!NOTE]
> The installer isn't code-signed yet, so Windows SmartScreen may say *"Windows protected your PC"*. Click **More info → Run anyway**. FreshOptimizer asks for administrator rights because network-card and power settings require them.

## 🛡️ Safety

FreshOptimizer is built to be boring where it matters.

| | |
|---|---|
| **No game injection** | No DLL injection, no reading or writing game memory, no hooks, no drivers, no "RAM cleaners". Game processes are only opened with *set priority* rights. If an anti-cheat blocks even that (Vanguard may), FreshOptimizer falls back to a launch-time priority setting that Windows applies itself. Each game's own rules still apply. |
| **Everything is undoable** | Before any change, the original value is saved to a restore point (kept in a folder only administrators can change). **Change history** shows every change with its old and current value; undo one tweak, or **Undo all** to put back registry values, network-card settings, DNS, TCP tuning, startup apps and your power plan, in reverse order. |
| **Clean uninstall** | The uninstaller can restore your original Windows settings before it removes the app, its shortcuts and its startup task. |
| **Updates from one place** | In-app updates only ever download from this repository's GitHub Releases. |
| **Honest numbers** | Measurements say what they measure: DNS speed comes from real lookups, the smoothness test reports a typical value and shows run-to-run differences, and the Riot route is labelled as Riot's website network because VALORANT servers don't answer pings. |
| **Nothing touches your game** | No new access to game processes for any measurement. Server ping comes from Windows' Kernel-Network event log (what Resource Monitor uses) plus a normal ping to that IP; GPU readings come from NVIDIA's own read-only NVML library. Background-app actions never target the game or anti-cheat processes (Vanguard, EAC, BattlEye, FACEIT, EA Javelin, GameGuard, ACE and more). No one but each game's publisher can promise what their anti-cheat allows, but nothing here behaves like a cheat. |
| **Read-only game checks** | The in-game settings check and FPS measurement never touch the game. PresentMon reads Windows' own graphics timing (ETW), the same way Task Manager does. It's only downloaded when you ask, pinned to Intel's v2.6.0 release and checked against its SHA-256 before use. |
| **Gentle with your apps** | Busy background apps can be lowered in priority (undone when your game closes) or asked to close the normal way. Nothing is ever force-closed, and Windows and anti-cheat processes are left alone. |
| **Small when closed** | Closing the window closes the whole interface, so only the small background engine stays in the tray. Turn this off in Settings to make closing quit the app. |
| **No telemetry** | No accounts, no analytics, no ads. Network traffic: pings you can see on screen, the optional update check, the lag test (Cloudflare's speed test servers, only when you run it) and the one-time PresentMon download. |

## 🏗️ Build from source

**Requirements:** Windows 10/11, [Node.js 20+](https://nodejs.org), [Rust](https://rustup.rs) (stable, MSVC), WebView2 runtime.

```bash
npm install
npm run dev        # UI in the browser with demo data
npx tauri dev      # the real app (run from an elevated terminal)
npm run dist       # release build + installer -> release/FreshOptimizer-Setup-<version>.exe
```

`cargo test --lib` in `src-tauri/` runs read-only hardware probes and a sandboxed registry backup and rollback test.

<details>
<summary><b>Architecture</b></summary>
<br />

| | Stack |
|---|---|
| **App** | Tauri 2 · React 19 · TypeScript · Tailwind · Framer Motion |
| **Core** | Rust · Win32 (`windows-sys`) · registry (`winreg`) · `netsh` · `powercfg` · NetAdapter / DnsClient PowerShell |
| **Installer** | Custom Tauri setup app (`setup/`): compressed payload, Program Files install, Windows *Apps* registration, self-copying uninstaller |

| Module | What it does |
|---|---|
| `restore.rs` | Restore point (`RestorePoint.json`): baseline saved before every write, persisted atomically, replayed in reverse on undo |
| `registry.rs` | Tracked registry writes; undo restores the raw value or removes it and any keys it created |
| `network.rs` · `dns.rs` | Network-card advanced properties by standard keyword, TCP tuning, DNS presets |
| `ping.rs` · `latency.rs` | Multi-threaded ICMP jitter / loss probe; user-mode DPC stall probe |
| `engine.rs` · `games.rs` · `prefs.rs` | Game detection, per-game settings, priority / affinity, timer and power plan in-match |
| `startup.rs` · `updates.rs` | Startup apps (Task Manager flags), launch-at-login task, GitHub update check |
| `fps.rs` · `advisor.rs` | PresentMon capture and summaries; read-only in-game settings check |
| `netwatch.rs` · `gpu.rs` · `report.rs` | Game-server detection from the Kernel-Network ETW log (`--netdiag <exe>` writes a log for support); NVML GPU readings; match reports |
| `checks.rs` | Wi-Fi link, driver age, overlays and the Health check |
| `matchtime.rs` · `display.rs` · `agent.rs` | Background-app watcher and Windows Update pause; refresh-rate check; tray, hotkey and settings that work with the window closed |
| `selftest.rs` | `--selftest <report.json>`: applies every change, verifies it, undoes it and verifies again. Run it in Windows Sandbox with `scripts/sandbox/run-selftest.ps1` |

## ❓ FAQ

<details><summary><b>Will this get me banned?</b></summary><br />
FreshOptimizer only changes Windows settings and never touches a game's memory or files. Nobody but the publisher can promise what their anti-cheat allows, so check your game's rules if you're unsure, but nothing here behaves like a cheat.
</details>

<details><summary><b>Why does the smoothness score change a little between tests?</b></summary><br />
Because your PC really is slightly different from one second to the next: Windows is always doing something in the background. The test runs for about 4 seconds, reports the typical moment rather than the single worst one, and shows your last few results so you can see the spread.
</details>

<details><summary><b>How do I undo everything?</b></summary><br />
Click the clock icon at the bottom of the sidebar, or <b>Undo all changes</b> on the Tweaks page. Uninstalling with "Restore my original Windows settings" switched on does the same.
</details>

<details><summary><b>Some tweaks say "Not needed"</b></summary><br />
Your PC was already set the right way, or your network card doesn't have that setting. Nothing is forced.
</details>

<details><summary><b>Why is it still running after I close it?</b></summary><br />
So it can switch to full power when you start a game. The window really closes (it uses almost no memory then); FreshOptimizer stays as a tray icon next to the clock. Right-click it and choose <b>Quit</b>, or turn off <i>Keep running in the tray</i> in Settings.
</details>

<details><summary><b>Why does the game server say "doesn't answer pings"?</b></summary><br />
Some servers (Riot's, for example) ignore ping requests. FreshOptimizer still finds the server your game is talking to, but it won't make up a number it can't measure.
</details>

<details><summary><b>Is the before/after FPS comparison proof that Boost works?</b></summary><br />
It's your real measurements, but FPS also depends on the map, graphics settings, game updates and what else is running. Treat a difference of a few percent as noise and compare several sessions on each side.
</details>

<details><summary><b>Do I need to restart?</b></summary><br />
Only for <i>Sharpen the system clock</i> and <i>Repair network stack</i>. Everything else applies straight away; the Nagle change applies to new connections.
</details>
